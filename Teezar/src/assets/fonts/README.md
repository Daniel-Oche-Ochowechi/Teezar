# Fonts Directory

Drop your Aglema font files here!
Supported filenames and formats:
- `Aglema.woff2` / `aglema.woff2`
- `Aglema.otf` / `aglema.otf`
- `Aglema.ttf` / `aglema.ttf`
- `Aglema-Bold.woff2` / `aglema-bold.woff2` (optional bold variant)
- `Aglema-Bold.otf` / `aglema-bold.otf`
- `Aglema-Bold.ttf` / `aglema-bold.ttf`
